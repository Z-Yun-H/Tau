# 终端界面（TUI）

`tau tui` 是全键盘的终端交互界面：同一个引擎、同一道审查门，只是把计划、审查与执行搬进了全屏 TUI。

```bash
tau tui
```

## 设计要点

- **键盘优先**：所有操作可在不碰鼠标的情况下完成，方向键/回车浏览与选择，快捷键参考界面内帮助。
- **ANSI 渲染**：计划说明与结果以 ANSI 文本渲染（基于与 WebUI 共享的 markdown 抽象层——`@tau/markdown` 同时输出 HTML 与 ANSI 两种形态）。
- **同样的门**：TUI 里看到的审查结论与确认请求，和 CLI / WebUI 完全一致；它不是"另一个更宽松的模式"。

## 什么时候用 TUI

- 想在终端里连续多轮对话而不想反复敲 `tau ask`；
- 通过 SSH 在远程机器上工作，没有浏览器；
- 喜欢全屏界面的专注感，但不想离开终端。

三兄弟的分工：**CLI** 一次性与管道，**TUI** 终端里的沉浸交互，**WebUI** 最丰富的可视化（思考面板、工具卡片、文件查看器）。引擎只有一个。
