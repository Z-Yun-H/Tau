# Changelog — 2026-09-02

## 变更摘要

将 `packages/ai/src/providers/` 的内部结构按 AGENTS/ai-integration.md 与
AGENTS/architecture.md 治理：把原本寄居在 `mock.ts` 里的 `chatJSON` HTTP
helper 抽到独立的 `providers/http.ts`，让 `mock.ts` 回归"零网络、自包含的
离线 demo / 测试 fixture"单一职责，并清掉 mock 顺手再导出的
`validatePlanResponse`（调用方本就直连 `prompt.js`）。`openai.ts` 与
`ollama.ts` 改从 `./http.js` 引入 `chatJSON`，`index.ts` barrel 同步暴露
`http.ts`。`deepseek.ts` 保持自有 SSE 流式客户端不动（其语义与 `chatJSON`
的非流式 POST 不同）。同步更新 `AGENTS/ai-integration.md` 与
`packages/ai/README.md` 中"添加 provider / 公开 API"两处的目录职责说明。

动机：mock 是"deterministic, zero-network"的 demo provider，原本却承担了
真实 provider 的共享 HTTP 工具仓库角色——这是结构边界泄漏，违反
AGENTS/ai-integration.md 对 mock 的定位与 AGENTS/conventions.md
"Adding an import that would create a cycle means the code is in the wrong
package — move it" 的同源原则（模块层）。重构后 mock 不再被任何真实
provider 导入，可独立审视、删除或替换。
